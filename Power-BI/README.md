# Power BI Dashboard – AI Hiring Fairness

## Overview

This project uses Power BI to create an interactive dashboard for analyzing hiring patterns and potential disparities across different candidate groups.

The dashboard presents hiring outcomes and key hiring-related insights through interactive visualizations.

## Project File

The Power BI file contains the interactive dashboard and visualizations created for the hiring analysis.

## Tools Used

- Microsoft Power BI
- Data Visualization
- Interactive Dashboards
