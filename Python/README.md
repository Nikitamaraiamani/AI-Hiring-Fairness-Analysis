# Python Analysis – AI Hiring Fairness

## Overview

This project analyzes hiring decisions and candidate characteristics to identify hiring patterns and potential disparities across different candidate groups.

The analysis was performed using Python in a Jupyter Notebook environment.

## Project File

The Jupyter Notebook contains the Python code, analysis, outputs, and visualizations used in this project.

## Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
